# Skill Index

Operational-skill router for Droid.

- Public API/source changes with user-facing docs impact -> `skills/documentation_sync_skill.md`.
- Independent patch/source/Git review -> `skills/patch_review_skill.md` when a structured review procedure helps.

Wrapper implementation/build/MCP procedures are already owned by dedicated local guides and do not need duplicate skill files.

Load at most one skill by default unless the task genuinely requires more.
