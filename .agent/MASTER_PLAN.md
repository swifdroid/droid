# Master Plan

Repository capability roadmap for Droid.

1. Build coherent classic Android view/widget coverage with exact Swift wrapper semantics.
2. Build coherent AndroidX and Material coverage without guessing unsupported APIs.
3. Strengthen framework/state/lifecycle/manifest/Gradle behavior as real application needs require it.
4. Keep JNI dependency usage safe and explicit while preserving JNIKit independence.
5. Keep generated-app/devcontainer build and wrapper-audit workflows reproducible.
6. Keep public documentation synchronized with verified user-facing APIs.

This roadmap is direction, not proof of implementation or authorization. Active approved work belongs in `TASKS.md` or an explicitly reviewed task plan.
